Lightness check (OKLCH L)

Solid line: new ramp, evenly stepped. Dashed orange: the doc's 5 steps in their stated order (10, 25, Main, 75, 100). The line goes back up at "75", which is the ordering bug.

Where each step is used

  • 700 #4A13B7: primary button, links. It's the current landing button colour, now part of the ramp.
  • 800 #2D0B84: all headings and button hover. This is the brand Main colour.
  • 900 / 950: pressed state, dark bands, the footer.
  • 50–200: tinted sections, selected rows, chips.

Rules

  • Text on white: use 600 or darker (≥ 6.2:1).
  • Never use 400–500 for text; they're only for decoration and illustrations.
  • The old #3A0E94 hover and #2E0B78 pressed are now 800 and 900.
